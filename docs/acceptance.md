# Приёмка

## Без интеграций

1. Открыть страницу на 390px и 1440px: все шесть разделов доступны, горизонтальная прокрутка не нужна.
2. Начать первый урок, заполнить каждый блок. После блока выражений проверить три словарные карточки.
3. Завершить мини-тест: два закрытых ответа проверяются точно, открытый ответ сохраняется без выдуманной оценки.
4. Перезагрузить страницу и продолжить незавершённый урок из истории. Повторное завершение первого квеста не добавляет ещё 50 XP.
5. Создать и отредактировать главу, скачать книгу, CSV словаря и JSON-резервную копию.
6. Пройти три игры. Подсказки не должны считаться интервальным повторением.
7. Нажать ИИ-разбор без интеграций: увидеть явное сообщение о недоступности; ответ урока остаётся в истории.

## С интеграциями, HTTPS и разрешением микрофона

1. Войти по email, создать урок, открыть второй браузер и увидеть облачную историю. Проверить запрет доступа к данным другого пользователя средствами RLS.
2. Записать голосовое в Safari iOS и Chrome Android; прослушать, скачать, расшифровать и исправить текст.
3. Получить исправление: исходный текст, минимальное исправление, объяснение, повторная попытка. Не принимать произвольные стилистические варианты за ошибки.
4. Собрать эссе: факты и смысл не дополняются. Исходник хранится отдельно от новой версии.
5. Начать WebRTC-разговор, завершить вручную и по лимиту. Проверить индикатор микрофона после выхода и сохранение реплик при обрыве.
6. Отклонить доступ к микрофону, отключить сеть, использовать просроченную auth-сессию: понятные сообщения, отсутствие ложных результатов.
7. Проверить повторение с подсказкой и без; успешное повторение требует воспроизведения выражения и нового осмысленного применения.

Браузерные сценарии не автоматизированы и не были выполнены в текущем окружении: инструмент браузера недоступен.
