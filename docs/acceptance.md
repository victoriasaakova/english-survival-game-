# Приёмка обновлённого сервиса

1. На телефоне доступны шесть разделов: Уроки, Новый урок, Словарь, Практика, Книга меня, Профиль. Нет островов, XP или A2-программы.
2. Создать роль со своими инструкциями в профиле. Выбрать её перед уроком, задать тему, формат, акценты и запрос. Убедиться, что они сохранены в карточке.
3. Отправить сообщение. Без API сообщение остаётся в диалоге, отображается понятная ошибка. Перезагрузка сохраняет черновик и историю; повтор запроса не дублирует пользовательскую реплику.
4. Сохранить свою реплику в Книге меня. Проверить её вид, тему, ссылку на исходный урок; отредактировать текст.
5. Добавить выражение с примером, отфильтровать по теме и найти поиском.
6. Экспортировать JSON, импортировать обратно; повреждённый файл отклоняется. В профиле B2 → C1; стрик учитывает только фактические пользовательские реплики.
7. На браузере с данными v1 сохраняются все уроки, ответы, словарь и главы; есть экспорт исходного архива.

## После подключения серверных API и авторизации

8. Провести свободный диалог и урок по скиллу с разными ролями. Проверить уровень B2–C1 и соблюдение пользовательского запроса.
9. Собрать конспект: отдельные языковой разбор и разбор от роли; тематический словарь; записи обо мне с точными цитатами и ссылкой на урок. Повторный анализ не дублирует записи, ручные записи сохраняются.
10. Создать новый урок из рекомендаций, проверить перенос запроса и ссылку на исходный урок.
11. Создать грамматические задания, переводы и письменную практику по выбранному уроку. Проверить сохранение первых ответов и отдельную повторную попытку; открытые ответы оцениваются по языку и смыслу.
12. Проверить запись и расшифровку на iOS Safari / Android Chrome. В realtime выбранная роль и тема используются, обе стороны сохраняются в чате, микрофон выключается после выхода.

Браузерные сценарии требуют ручной проверки; браузерный инструмент в текущей среде отсутствует. Реальные ИИ-операции не проверены без действующей интеграции.
