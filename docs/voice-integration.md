# Голосовой ChatGPT и личный сервис

Проверено по официальной документации OpenAI 18 ноября 2026.

## 1. Голос остаётся в ChatGPT

Готового публичного компонента, который встраивает существующий личный ChatGPT-чат и его Voice в сторонний сайт, в просмотренной документации нет. Обычный вход через ChatGPT не предоставляет автоматически доступ к беседам и памяти.

Уже реализован минимальный маршрут без API-ключа: в уроке раскрыть «Продолжить голосом в ChatGPT», скопировать роль, правила, игру и контекст, открыть ChatGPT, вставить и включить Voice. После разговора вернуть Markdown/TXT или текст в тот же урок. Импорт сохраняется как исходный документ, а не выдуманная стенограмма/новая выполненная практика.

Автоматизация этого маршрута — отдельная интеграция: ChatGPT Live поддерживает доступные пользователю плагины. Можно создать авторизованный MCP-сервер сервиса с инструментами `get_lesson_context`, `append_lesson_messages`, `save_lesson_note`, `upsert_vocabulary`, `save_personal_materials`. ChatGPT должен отправлять конкретный контекст/результат, а сервер — проверять владельца, схему, source IDs и идемпотентность. Нельзя рассчитывать на автоматическое чтение всей памяти или фонового доступа ко всем чатам. Серверное хранилище обязательно: текущий localStorage телефона недоступен внешнему MCP-серверу. Эта интеграция пока не реализована.

## 2. Голос внутри сервиса

Используется отдельная API-сессия: HTTPS-страница с разрешением микрофона → WebRTC → серверный обмен SDP или краткоживущий client secret → Realtime API. Ключ проекта хранится только на сервере. В сессию передаются роль, пользовательские правила, выбранная игра и история урока; события транскрипции обеих сторон связываются с lesson ID. Выход останавливает микрофон. Модель и доступ к ней определяются проектом; интерфейс не должен обещать идентичность всем свойствам ChatGPT Voice.

В исходниках есть серверный `/api/realtime` с унифицированным `/v1/realtime/calls`, проверкой Supabase-сессии и WebRTC-клиентом. Он получает обновлённые игровые правила. Опубликованная версия статическая, без подключённого backend/API-key; живой разговор не объявляется работающим.

API имеет отдельный биллинг. Sign in with ChatGPT поддерживает использование плана только в участвующих приложениях, при доступности функции и явном выборе; это не перенос существующего Voice-чата и не автоматическое право использовать подписку для произвольных API-запросов.
