# Innerworld — личное обучение B2 → C1

Личный English workspace: диалоги с настраиваемыми ролями, конспекты, тематический словарь, практика и материалы о себе. Next.js / React / TypeScript.

## Структура

- **Уроки:** отдельные карточки чатов. Диалог, исходный запрос, роль и её инструкции, черновик, конспект, разбор языка и разбор от роли. Можно продолжить разговор, запросить практику и создать следующий урок из разбора.
- **Новый урок:** роль, тема или своя тема, формат, акцент и свободный запрос. Предустановлены рекрутер/продакт, личный собеседник, селф-коуч; инструкции редактируются в профиле.
- **Словарь:** выражения из анализа урока с темой, значением, примером и ссылкой на источник. Можно редактировать и добавлять свои карточки.
- **Практика:** задания по конкретному уроку: грамматика, переводы, эссе и письмо. Первые ответы сохраняются; повтор — отдельная попытка. Сценарные игры запускаются внутри чата.
- **Книга меня:** истории, убеждения, карьерные материалы, выводы и письменные работы. Исходные слова отделены от интерпретаций. Автоматическая запись допускается только с точной цитатой из сообщения пользователя.
- **Профиль:** B2 → C1, реальные дни активности, общие правила, собственные роли, обратная связь по разобранным урокам, экспорт и восстановление данных.

Убраны острова, XP, начальная программа A2 и отдельная игровая карта. Скилл [adaptive-language-coach](https://github.com/victoriasaakova/adaptive-language-coach) применяется в формате «Урок по скиллу». Свободный диалог и пользовательские сценарии не принуждаются к фиксированной последовательности блоков.

## Запуск

Node.js 24+:

```sh
npm ci
npm run dev
```

## API и интеграции

Серверные маршруты `/api/lesson`, `/api/transcribe`, `/api/realtime` используют серверный `OPENAI_API_KEY`. Все ИИ-маршруты проверяют Supabase-сессию. Создайте `.env.local` по `.env.example`, примените `supabase/schema.sql` и настройте Supabase Auth. Ключ OpenAI не передаётся клиенту. При настройке Supabase в профиле появляется вход по почте. Без авторизации ИИ-вызовы закрыты; интерфейс не имитирует ответы. Для интегрированного запуска необходимо подключить ключ и серверное размещение. Персональные данные сейчас сохраняются локально в браузере, без облачной синхронизации.

`/api/lesson` принимает task `chat`, `analyse`, `practice`, `evaluate`; конфигурацию урока, актуальную историю и пользовательские правила. Анализ по реальному диалогу формирует конспект, словарь, материалы о пользователе и рекомендации следующего урока. Повторный анализ заменяет ранее сгенерированные записи, сохраняя ручные материалы.

Запись голосового использует MediaRecorder; расшифровка — серверный API. Realtime использует WebRTC и выбранную роль, тему и историю. Полученные реплики обеих сторон сохраняются по мере появления, до 7 минут за сессию. До подключения ИИ эти функции показывают явную ошибку; текст сохраняется без подставных ответов.

## Данные

Новая схема: `innerworld.workspace.v2`. При первом запуске мигрирует локальная гостевая история первой версии; исходная структура сохраняется в `legacy` и под прежним ключом браузера. Архивные материалы не выдаются за новые B2-уроки. Поддерживается экспорт/восстановление JSON и Markdown-экспорт книги. Импорт заменяет данные только после явного подтверждения. Повреждённая копия не перезаписывается.

## Проверка

```sh
npm test
npm run typecheck
npm run build
```

Тесты: миграция истории, независимость ролей и снимок инструкций урока, отсутствие выдуманных персональных записей, повторный анализ без дубликатов, сохранение ручных записей, реальные стрики, валидация импорта, прежние SRS-правила и закрытый доступ к API.

## Размещённая версия

Приватный мобильный просмотр: https://innerworld-english-victoria.victoriss.chatgpt.site

Статическая сборка для него хранится отдельно в `/workspace/innerworld-mobile`, использует тот же интерфейс и модель данных. Там доступны локальные карточки уроков, настройка ролей, история, ручные записи и экспорт. Для автоматических ответов, анализа, тестогенерации и речи нужны серверные API — они пока не подключены к опубликованной версии. Просмотр интерфейса не означает завершённую ИИ-интеграцию.
