# Innerworld · English Survival Game

Личное веб-приложение для английского через истории о себе. Next.js / React / TypeScript. Методика: [adaptive-language-coach](https://github.com/victoriasaakova/adaptive-language-coach), версия `00eb2351faff6e3f1f3f0c9821a773b7149dbb43`.

## Реализовано

- Адаптивные страницы: сегодня, карта, уроки, словарь, голос, книга.
- Пять маршрутов A2 на острове «Кто я», семь блоков урока, выбор 15/30 минут, мини-тесты на 3/5 заданий, история ответов и продолжение занятия.
- Словарь выражений, примеры, озвучка браузером, экспорт CSV, интервальные повторения D+1/3/7/14 с точными правилами исходного скилла.
- Книга: создание, редактирование, удаление глав, исходник отдельно от ИИ-редактирования, Markdown-экспорт.
- Запись через MediaRecorder, прослушивание и скачивание; серверная транскрипция; WebRTC-разговор с OpenAI Realtime (максимум 7 минут).
- Три игры: сборка фразы, вспоминание выражения, диалог. XP за первый завершённый маршрут, без штрафов за пропуски.
- Локальная история, полный JSON-экспорт. При подключении Supabase — вход по почте, облачная копия и изоляция данных через RLS.
- Серверные ИИ-операции требуют действующую Supabase-сессию. Ключ OpenAI никогда не отправляется в браузер.

## Запуск

Node.js 24+:

```sh
npm ci
npm run dev
```

Для уроков, игр, словаря, книги и локального сохранения ключи не нужны. Серверные ИИ-функции возвращают понятное сообщение, если интеграции не настроены; фиктивные ответы не подставляются.

## Облачное подключение

1. Создать локальный `.env.local` по `.env.example` (файл игнорируется Git).
2. Указать URL и публичный anon key Supabase, выполнить `supabase/schema.sql` в нужном проекте.
3. Для личного запуска отключить публичную регистрацию в Supabase Auth, создать свой аккаунт и добавить URL приложения в разрешённые redirect URLs. Использовать только публичный anon key на клиенте.
4. Добавить серверный `OPENAI_API_KEY` через секреты выбранного хостинга. Имена моделей можно поменять серверными переменными.
5. Войти в приложении по ссылке из письма. Облачная история загружается отдельно от гостевой. Одновременное редактирование с нескольких устройств пока использует последнюю запись; автоматического слияния нет.

Приложение требует хостинг Next.js с серверными маршрутами (`npm run build`, затем `npm start`). Статический GitHub Pages не подходит для API. Манифест поддерживает запуск с главного экрана; офлайн-кеширование и push-уведомления не реализованы.

## Проверки

```sh
npm test
npm run typecheck
npm run build
```

CI повторяет эти проверки. Тесты покрывают календарные интервалы, просроченные этапы, подсказки, ранние попытки, перезапуск цикла и защиту XP от повторного начисления.

## Текущие ограничения

- Первые пять маршрутов подготовлены заранее. Перед уроком можно адаптировать шесть учебных блоков под интересы и последние разборы, сохранив грамматику и выражения. ИИ также разбирает ответы и редактирует эссе. Полная автоматическая генерация учебной программы и отдельные оценки навыков — следующий этап.
- На пяти остальных островах можно перейти к свободному письму и голосу; полноценные сюжетные маршруты пока есть только на первом острове.
- Открытые задания мини-теста сохраняются без автоматического общего балла. Оценка закрытых заданий показана отдельно. Игра и посещаемость не означают повышение CEFR.
- Текстовый разбор не оценивает произношение. Голосовой разговор сохраняет расшифрованные реплики пользователя; отдельный аудио-анализ произношения не реализован.
- Аудиофайл записи живёт до выхода из голосового компонента; его можно скачать. Постоянное облачное хранение аудио не подключено.
- Supabase, OpenAI и production-хостинг не были настроены в окружении разработки. Реальные ИИ-вызовы, вход по почте, WebRTC и мобильная запись требуют проверки с действующими интеграциями.
- Локальные данные принадлежат браузеру: очистка браузера удалит их. Доступен JSON-экспорт; восстановление из импорта пока не реализовано.
