# english coach

Личный English workspace: диалоги с настраиваемыми ролями, конспекты, тематический словарь, практика и материалы о себе. Next.js / React / TypeScript.

## Разделы

- Главная показывает стрик, уроки за неделю, цель и следующий урок из разбора. Здесь открываются настройки и повторение карточек.
- В новом уроке выбираются роль, режим, акценты и формат общения. Базовые роли — рекрутер, продакт, коуч и эзотерик.
- В каждом уроке есть диалог, конспект и тест. Сообщения и результаты хранят ссылку на занятие.
- В словаре доступны выражения по темам, флеш-карточки и повторения через 1, 3, 7 и 14 дней.
- «Обо мне» хранит истории, рефрейминги, карьерные материалы и видение будущего. В «Что прокачать» попадают рекомендации из уроков и проверенных заданий.
- В практике можно открыть тест по уроку или выбрать тему, уровень и тип задания.

## API и интеграции

Серверные маршруты `/api/lesson`, `/api/transcribe`, `/api/realtime` используют серверный `OPENAI_API_KEY`. Все ИИ-маршруты проверяют Supabase-сессию. Создайте `.env.local` по `.env.example`, примените `supabase/schema.sql` и настройте Supabase Auth. Ключ OpenAI не передаётся клиенту. При настройке Supabase в профиле появляется вход по почте. Без авторизации ИИ-вызовы закрыты; интерфейс не имитирует ответы. Для интегрированного запуска необходимо подключить ключ и серверное размещение. На приватном сайте авторизацию обеспечивает вход в ChatGPT. Профиль, уроки и словарь синхронизируются через приватный объект R2, привязанный к аккаунту. Браузер сохраняет локальные изменения и догружает их при восстановлении связи.

`/api/lesson` принимает task `chat`, `analyse`, `practice`, `evaluate`; конфигурацию урока, актуальную историю и пользовательские правила. Анализ по реальному диалогу формирует конспект, словарь, материалы о пользователе и рекомендации следующего урока. Повторный анализ заменяет ранее сгенерированные записи, сохраняя ручные материалы.

Запись голосового использует MediaRecorder; расшифровка — серверный API. Realtime использует WebRTC и выбранную роль, тему и историю. Полученные реплики обеих сторон сохраняются по мере появления, до 7 минут за сессию. До подключения ИИ эти функции показывают явную ошибку; текст сохраняется без подставных ответов.

## Данные

Новая схема: `innerworld.workspace.v2`. При первом запуске мигрирует локальная гостевая история первой версии; исходная структура сохраняется в `legacy` и под прежним ключом браузера. Архивные материалы не выдаются за новые B2-уроки. Поддерживается экспорт/восстановление JSON и Markdown-экспорт книги. Импорт заменяет данные только после явного подтверждения. Повреждённая копия не перезаписывается.

## Размещение и подключение проекта ChatGPT

`npm run build:site` собирает приватный сайт в `dist/` с сервером диалога, хранилищем и MCP. Браузерный вход в Sites привязывает данные к одному аккаунту на разных устройствах.

В чате проекта «Английский» выберите персональное приложение english coach. Фраза «сохрани этот урок в english coach» передаёт конспект и исходные реплики текущего занятия. Для продолжения уже начатого на сайте урока скопируйте запрос из карточки диалога. Доступ к другим чатам и файлам проекта для этого не требуется.

## Материалы и режимы урока

Scenario Challenge, Future Self Files (2031) и Inner Critic Board используют правила из переданных заметок. Для режима «Три роли» состав участников выбирается в настройке урока. Текстовый и голосовой тренеры получают снимок выбранных инструкций.

Обновление скилла применяется с разрешением конфликта в пользу текущей цели пользователя B2 → C1, без возврата к исторической цели B2. Сохраняются одно задание за раз, stop/summary, отсутствие принудительных интонационных упражнений, оригинальная продукция вместо повторения, разная глубина исправлений по режимам. Конспект получает шесть обязательных разделов и опциональный Future Self log.

Персональная библиотека собирается `scripts/build-personal-library.py` из трёх явно переданных файлов. Она содержит 441 уникальное по нормализации выражение и 16 новых наборов практики, включая 56 грамматических заданий из журнала исправлений. Исходные словарные примеры не считаются подтверждением автобиографических фактов. Импорт идемпотентный; существующие записи и пользовательские роли не перезаписываются; активное владение и даты успешных повторений не выдумываются. Повторения D+1/3/7/14 запускаются отдельно после активации, с проверкой самостоятельного извлечения и нового применения.

`public/personal-library.json` игнорируется публичным репозиторием GitHub. Его можно включать только в приватный Site пользователя. Не коммитить исходные загруженные заметки или личный датасет в публичный репозиторий.

В чате добавлен перенос контекста в ChatGPT Voice и обратный импорт конспекта. Для передачи из текущего разговора проекта также есть приложение english coach с инструментами get_english_lesson, save_english_lesson и reply_to_english_lesson. Повторное сохранение использует тот же идентификатор занятия. Варианты дальнейшей интеграции описаны в `docs/voice-integration.md`.
